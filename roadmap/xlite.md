# Roadmap — xlite (Godot iso-tactics game)
**Maturity:** MVP+ (playable). **Stopping point:** a shippable desktop tactics game with enough content + polish; then mobile port, then maintain. Don't turn it into a live-service game.

- [ ] [P2] [decomposed] Mission variety + campaign arc — Adopt Into the Breach's model: a small fixed set of ~6 objective types (Protect/Escort, Destroy Target, Hold Position N turns, Extract Before Timer, Non-Lethal/Don't-Kill using existing suppression predicates, Survive Escalating Waves) combined with varying hand-authored terrain/enemy layouts, since combinatorial reuse of few objective types is what lets a solo dev generate real variety without a mission generator. Structure the campaign as a short linear "chapter" spine (3 acts x ~5 missions, Wildermyth-style) with occasional binary branch points offering a choice of one of two hand-authored missions per branch, giving light replayability without doubling total authored content.
