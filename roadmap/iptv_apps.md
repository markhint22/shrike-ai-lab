# Roadmap — Chickadee / iptv_apps
**Maturity:** HIGH (~95% — live, multi-platform). **Stopping point:** once DVR+VOD+multistream ship and it's in both app stores, it's feature-complete → maintenance + content-ops only. Don't chase Fubo's channel count.

## P1 — competitive parity + store launch (next ~2 quarters)
- [ ] [P1] [decomposed] Cloud DVR — record/list/delete, retention policy, RecordingsView — every rival has it {cat: backend+web; size: L; multifile: yes; research: repo}
- [ ] [P1] [decomposed] VOD / on-demand catalog + tab — Sling Freestream angle {cat: backend+web; size: M; multifile: yes; research: repo}

- [ ] [P1] [decomposed] App Store + Play Store submission blockers — RevenueCat is already SDK-wired for iOS/Android with API keys and product IDs configured, but Apple Guideline 3.1.1 and Google Play's subscription policy both mandate native in-app purchase (not Stripe) for any digital subscription bought inside the app, so remaining IAP work is finishing App Store Connect/Play Console product setup plus sandbox testing, not new integration. The bigger blocker is content rights: Chickadee's Xtream/M3U playlist-import architecture is exactly the pattern Apple's 5.2.2/5.2.3 guidelines target, and reviewers will require documentary proof — a signed licensing contract or authorization letter from each channel/content rights-holder — attached in App Review Information, or rejection is near-certain. That proof-of-rights posture is a business call Shrike Labs must make (license specific channels vs. reposition as a bring-your-own-already-licensed-playlist player with matching ToS/UI), and can't be resolved by coding alone. Sequencing: finish RevenueCat/IAP store-side config and sandbox tests now (buildable), settle the content-rights/licensing decision next, then submit with the authorization documentation attached last. {cat: infra; size: M; multifile: yes; research: none — completed 2026-09-10, sources: developer.apple.com/app-store/review/guidelines (3.1.1/5.2.2/5.2.3), support.google.com/googleplay/android-developer/answer/10281818}
